# 会议录音转写 + 会议纪要

## 何时触发

- 用户给出**录音文件**要求转写文字或生成会议纪要；
- 用户说「开完会了，帮我整理纪要」「这段录音转一下」「会议录音总结」；
- 用户直接丢一个音频文件过来说「转一下」或「总结」。

## 工具路径

```text
WhisperVoiceIME 项目根目录 = C:\Users\servi\Documents\GitHub\whisper-voice-ime
转写脚本 = C:\Users\servi\Documents\GitHub\whisper-voice-ime\transcribe_wav.py
项目虚拟环境 = C:\Users\servi\Documents\GitHub\whisper-voice-ime\.venv\Scripts\python.exe
```

## 工作流（严格按序）

### 1. 转写录音

```bash
cd "C:/Users/servi/Documents/GitHub/whisper-voice-ime"
uv run --no-sync transcribe_wav.py "录音文件路径"
```

支持格式：wav / mp3 / m4a / mp4 / flac / ogg / aac / wma / webm / mkv

先确认常驻 ASR 服务已就绪（本机 127.0.0.1:8765/health）。CLI 使用 auto_start=False，不会自行启动服务；缺服务时，在独立受控后台进程从项目目录运行 `uv run --no-sync asr_service.py`。模型首次编译实测可达 170 秒，健康请求也可能暂时超时；不能因此重复启动 NPU 服务。只停止本任务启动的服务，不重启用户已有进程。

当前 CLI 统一调用 meeting_pipeline：短音频可为单段，长音频分段；产物为当前 cwd 的 `<音频名>_<时间戳>.md`。不要依赖历史的同名文件或 recordings/ 路径。脚本不支持 --help，会把它当文件名。

### 2. 读取转写产物

转写完成后，读取生成的 `.md` 文件获取文字内容。

```bash
# 查看产物
ls -lt "C:/Users/servi/Documents/GitHub/whisper-voice-ime/"*.md
# 优先使用本次命令返回的路径；不要直接把最新文件当作本次产物。
```

### 3. 生成会议纪要

基于转写文字，按以下结构输出会议纪要：

```markdown
# 会议纪要

## 会头
- **主题**：[从内容推断]
- **时间**：[录音时间或从内容推断]
- **出席**：[从发言推断，不确定标「待确认」]

## 决议（已拍板事项）
1. [一句一条，不含讨论过程]
2. ...

## 行动项（可勾选）
- [ ] [事项] — 负责人：[姓名/待确认] / 截止：[日期/待确认] / 完成标准：[具体标准]
- [ ] ...

## 待决与分歧
- [没定的事项，单独列出]

## 备忘
- [影响后续的上下文，原话只在容易误解时引用]
```

纪要规则（来自「日常办公」场景要求）：
- 结论先行，版式干净，数字与事实必须有依据；
- 语气中性、可转发，不要写成聊天记录；
- 不清楚的信息标「待确认」，不要编造；
- 把录音中的讨论过程压缩为「决议」，不要逐字搬运。

### 4. 交付

- 将会议纪要保存为 `.md` 文件，放在任务工作目录内；
- 告知用户文件路径；
- 同时输出纪要正文供预览。

## 强制验证（每次执行后必做）

1. **确认转写成功**：检查 `.md` 产物已生成且非空；
2. **读取转写内容**：至少读前 50 行，确认语言/内容对得上；
3. **纪要完整性**：检查是否包含「会头 / 决议 / 行动项 / 待决 / 备忘」五个板块；
4. **数字/人名核对**：纪要中的关键数字、人名必须能在转写原文中找到依据。

## 已知坑

1. **首次启动慢**：ASR 服务首次加载 NPU 模型需 60-90 秒，后续复用进程不再重载；
2. **转写错字**：专业术语可能有误，需结合上下文判断；
3. **非中文录音**：Whisper medium 支持多语言，但中文效果最佳；
4. **噪音干扰**：背景噪音大时转写质量下降，建议会议环境保持安静；
5. **长录音耗时**：实时因子约 6-12×，25 分钟录音约需 4 分钟转写。

## 耗时参考（Intel Core Ultra 9 285H + NPU）

| 音频长度 | 推理时间 |
|---|---|
| 5 秒 | ~0.4 秒 |
| 30 秒 | ~2.5 秒 |
| 1 分钟 | ~5 秒 |
| 5 分钟 | ~25 秒 |
| 25 分钟 | ~4 分钟 |

## Boundary / Output Contract

已有文字会议记录的摘要不调用 ASR；图片文字识别走 npu-ocr。交付本次音频对应转写与纪要，保留数字/人名不确定项；无音频输入时先定位文件，不复用无关历史产物。

Trigger/boundary regression prompts: `evals/trigger.json` (load during evaluation, not ordinary execution).
