## What Origin Can Do

When this skill triggers, treat Origin as a broad scriptable scientific-analysis toolbox. Before planning the task, load `references/origin-capabilities.md` when the request involves anything beyond simple import/status/column listing.

Main capability families:

1. **Data import and worksheet management**
   - Excel/CSV/text import
   - worksheet metadata, labels, designations
   - derived columns and formula columns
   - reduce/resample/restructure large data

2. **Descriptive statistics and distributions**
   - N, mean, SD, min/max
   - median, quantiles, frequency counts
   - distribution statistics and normality tests
   - outlier tests

3. **Correlation and multivariate relationships**
   - Pearson/Spearman/Kendall correlation
   - partial correlation
   - scatter relationships
   - cross-correlation for two time signals
   - coherence for frequency-domain relationship

4. **Signal processing**
   - Savitzky-Golay / adjacent averaging / LOWESS / LOESS smoothing
   - FFT / PSD / IFFT
   - STFT time-frequency analysis
   - digital filtering / FFT filtering
   - convolution / deconvolution
   - Hilbert transform / phase unwrap / envelope
   - decimation

5. **Fitting and calibration**
   - simple linear regression
   - multiple linear regression
   - polynomial fitting
   - exponential / sigmoidal fitting
   - nonlinear fitting
   - residual analysis and fit comparison

6. **Peaks and baseline**
   - peak finding
   - multiple-peak fitting
   - peak center / height / width / area
   - baseline-region detection
   - subtract reference / subtract baseline

7. **Plotting and visualization**
   - line / scatter / line+symbol
   - multi-layer / double-Y
   - 3D / contour
   - probability / Q-Q plots
   - diagnostic overlays

8. **Instrument-R&D workflows**
   - signal vs baseline classification
   - calibration / transfer functions
   - noise / stability / drift
   - FFT / periodic interference
   - two-sensor delay / velocity by cross-correlation
   - temperature compensation
   - peak/spectral analysis

The detailed intent → X-Function map is in `references/origin-capabilities.md`.
