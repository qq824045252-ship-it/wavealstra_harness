## 设计与行为

- 两张 Library 参考图已分别物化并实际查看。借鉴低干扰层级、圆角输入框和弱化元信息；桌面长回复保持开放阅读区，窄屏使用灰色圆角容器。
- 正文、回执与输入区统一使用应用现有 `--font-ui-size`，默认 15px，支持既有 12–20px 设置。辅助文字随设置变化并保留 11px 下限；代码字体设置继续由原 Markdown 渲染器处理。
- 阅读列最多 760px，并继续服从现有更窄的列宽设置。窄屏头部操作收敛为一行，较大字号下可横向访问，保留所有入口。
- 每条消息右侧用图标承载回复/补充与停止，保留 accessible name、title、键盘焦点与触屏 44px 规则；停止始终可发现。
- 输入区右侧并列发送和停止。停止只绑定一条前台回复的 requestId，tooltip 标明对应问题；并发发送继续可用，不取消后台 Work。原有归档保护保留。
- 用原生 details/summary 折叠用量与速度，完整统计和说明仍可展开；未知、错误、工具活动及需处理状态继续显示在消息区域。
- 左栏保留个人 Bot、显示分组和团队分区；统一名称、状态、行间距，使用团队图标，长名称保留完整 title。分组、归属和导航逻辑保持。
