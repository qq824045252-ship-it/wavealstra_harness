# Bot 工作空间与执行设置

Bot 设置中可以保存工作目录、模型、专家，以及额外 Skill / MCP / 连接器。保存立即持久化，不需要另走专家采用流程。

- 模型用于下一条前台对话及后续新 Work。跟随默认模型可留空；明确选择的模型不可用时前台明确报错，不默默换模型。
- 专家指令用于前台和新任务；完整技能包及 MCP/连接器通过现有专家快照装配到真实后台执行。前台仍负责沟通与委托，不宣称它直接运行这些业务工具。
- 每个 Bot 自动拥有独立的空间分组与默认工作目录。可选择已有文件夹。旧 Work 的路径、模型和已有执行快照不因修改设置迁移。
- 空间仅分组，不绑定可变 path；执行路径来自持久 Work 设置。这样普通空间目录跟随机制不会把旧 Bot 任务移到新目录。
- 团队成员共享负责人事项的工作目录，但模型使用成员自己的配置；已开始的执行不受设置更新影响。
- 设置仅选择已有、已启用的能力，不自动安装连接器、认证账户或新增凭据。选择失效会给出错误。专家自带能力随专家挂载，不必逐项重复选择。
- 本轮使用附加表保存配置，不提升数据库版本，不触发旧数据库重建，也不迁移或删除用户真实数据。

验证入口：`test:bot-settings`（持久化/派发行为）和 `test:bot-settings-dev`（隔离 profile 的真实 Electron UI；默认 HTTP 夹具）。`BOT_SETTINGS_LIVE=1` 使用本机已有 Magpie 3425 的 DeepSeek，读取测试临时目录中未透露的随机标记，不读取真实用户凭据。
