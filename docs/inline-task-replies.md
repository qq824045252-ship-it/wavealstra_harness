# 原回复内的任务进度

Bot 对话把同一任务的进展、核对记录和结果放入原来的助手回复。底部输入框、附件、引用、发送和前台停止操作保持原有位置与行为。阶段 Tab 只控制本条回复显示的内容，不改变发送目标，也不执行任务控制。

## 关联和历史

- `botTaskTimeline()` 使用 `botId + teamId + conversationId + workId` 的持久关联归并反馈，不根据标题、文字或相邻消息猜测任务。
- 原回复和已输出的流式片段保留；一个回复创建多个任务时，每个任务有独立的阶段面板。
- 已完成、流式、失败和旧版本反馈都保留。普通后续问答仍按原消息显示。
- 原回复尚未加载时，第一条反馈临时承载任务。加载更早历史后恢复到原回复，用户选中的阶段按作用域和任务保留。
- 收到的协作消息按全部已呈现消息 ID 去重，包含嵌入阶段中的反馈；原消息 ID 和精确版本关联继续有效。

## 阶段和状态

当前使用可由现有数据证明的生命周期阶段：**任务、执行、核对、结果**。这不是自动生成的未来步骤计划；不会把工具调用数、消息数或已核验的部分成果换算成完成百分比。

- 任务：关联的委托和目标。
- 执行：执行进展、问题及已核验的部分成果。
- 核对：后台结果与前台核对、继续处理或补充信息的记录。
- 结果：最终交付和关闭记录，包括取消、未完成等非成功结论。

紧凑 Work 摘要使用宿主提供的状态；摘要中省略的数组不代表没有执行或成果。历史修订、输入快照及已失效执行的成果不会提升当前阶段，原内容仍可查看。收到后台结果不等于整项任务成功，持续任务的一轮完成也不代表持续委托结束。

## 阅读和性能

每个任务独立保存选中的 Tab。新增进度、结束或重试只更新状态，不自动切换用户正在阅读的阶段。切换阶段暂停线程自动跟随，保留阅读位置；“查看当前阶段”由用户主动选择。键盘左右方向键、Home、End 只切换所在任务的阶段。

阶段面板按首次访问渲染正文，访问过的面板保留组件状态。进度来自现有消息和 Work 摘要，不为每个任务轮询完整详情或执行会话。活动监控跳转到消息时，会先展开对应阶段。
