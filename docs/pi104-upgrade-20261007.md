# MyBuddy / Pi 1.0.4 升级验收

日期：2026-10-07。Pi Coding Agent、Pi Durable 从 1.0.0 升级至 npm 官方 latest 1.0.4，九个 Earendil 相关包及独立子代理版本一致。升级验收时 MyBuddy 产品版本为 0.1.8；随后加入归档内容批量彻底删除并发布 0.1.9，Electron 为 44.5.1。

## 已适配

| 范围 | MyBuddy 行为 |
| --- | --- |
| Azure provider 改名 | 首启在 ModelRuntime 加载前迁移 auth/models/settings、任务和定时任务的未来模型选择；保留 `.pre-pi104-azure.bak` 原文备份，凭据使用 Pi 原生锁，旧/新配置冲突时拒绝覆盖。API ID `azure-openai-responses` 保持不变。 |
| 旧会话和角色 | Bot 已保存的 AgentDoc、运行 checkpoint、能力工具上下文及子代理 Markdown 中的旧 Azure 选择，在查询边界解析为 `azure`。不重写历史对话、用量记录或角色原文。 |
| 分层采样 | `samplingParamsByThinkingLevel` 使用 Pi 原生类型，贯通模型 JSON 编辑、保存、实际请求和主会话/子代理配置一致性检查。同步官方登录默认模型。 |
| Windows Bot | Native 和 Code Mode 均注册 Durable 原生 PowerShell；覆盖 argv、UTF-8、工作目录和配置刷新。继续由 Durable 负责队列、重试、取消与恢复。 |
| 图片 | AgentSession Code Mode 原生承接 `tools.read()` 图片返回和 `image()` 文件保存。Bot 加入原生环境图片读取、按内容去重落盘、产物卡片、重启恢复；落盘失败保留图片内容和诊断，不重放已执行的工具。 |
| MCP | 透传 `oauth.clientRegistration: "dcr" / "cimd"` 和工具曝光通配符；旧 Azure provider auth 兼容映射。Bot 使用 Pi 原生 OAuth provider，承接主动刷新、跨进程锁、刷新令牌保存与 scope challenge。 |
| 桌面嵌入 | 对 1.0.4 重放 worker/WASM、参考文档、MCP 状态/授权控制及认证后端导出补丁；保留上游新的 worker 与项目覆盖实现。CommandCode reasoning delta 兼容补丁仍有效。 |

### 能力边界

MCP 的宿主主会话和 Bot 继续读取 MyBuddy 能力管理页的解析配置；本轮没有添加任意工作目录 `.pi/mcp.json` 自动加载。Pi 原生 CLI 的项目覆盖、工具选择通配符和 `--no-mcp` 随独立子代理运行时升级。

Bot QuickJS 通过已注册 Durable 工具执行。已发布的 Durable 1.0.4 没有 ToolExecutionApi.models；`models.classify()` / `models.generateImages()` 由编码 AgentSession 的 Code Mode 原生支持，不将上游未发布 API 计作 Bot 已支持功能。

## 验证

- 类型检查：`pnpm -s typecheck`、`remote:typecheck`。
- 新版专项：`test:pi104-model-compat` 8 项、`test:pi104-features` 19 项全部通过；实际核对九个已安装包及其 Earendil 依赖均为 1.0.4。
- Durable：`test:durable-bot`、`test:gateway-durable`、`test:slack-gateway`；真实 1.0.0 JSONL fixture 覆盖旧历史、队列恢复、unsafe 工具中断不重复执行、旧 Azure checkpoint、provider session UUID、图片持久化与有效 PNG 解码。
- AgentSession：原生控制、生命周期、自主工具执行、压缩、宿主控制、MCP 配置、reasoning stream、模型刷新、登录、model admission、子代理模型选择及 Code Mode 规则回归通过。
- 代码边界：审计 736 个文件、14 个 hooks、99 个调用点，0 项违规；审计脚本适配当前 TypeScript 7 工具链，另经隔离负向断言验证。
- 构建：主程序、远程前端、QuickJS worker/WASM、独立 Pi 子代理构建通过；better-sqlite3 和 node-pty 按 Electron 重新编译。
- 打包：224 个 `out/main` 资源与 ASAR/解包文件逐一 SHA-256 比对通过，独立 runtime 中九个 Earendil 包为 1.0.4。
- 独立子代理：新包在隔离工作目录使用真实模型读取随机 nonce 文件并计算 sum；成功调用 read，不依赖源码 cwd 或外部 Pi，临时凭据已清除。
- 桌面新包：16 项真实 Electron/renderer/IPC 验收通过，117 秒、37 次本地 HTTP fixture 请求；图片解码显示、重复输出去重、删除原附件后整应用重启恢复、队列继续、unsafe 不重复执行、记忆/用量去重和 Gateway 通过。

主会话图片/分类器、Azure 配置、OAuth 和 Durable 的模型/传输响应使用隔离 fixture；没有宣称所有外部提供商账号和图像生成端点均已实测。桌面实际程序验收及入口部署记录见 `artifacts/pi104-upgrade/`。
