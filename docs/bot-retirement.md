# 独立 Bot 模式清理

2026-11-17：独立 Bot 模式已经移除。历史记录继续从原始持久化记录读取，Goal 继续使用现有 Work 权威数据。

## 当前边界

- `BotWorkApi` 只提供 `history`、`workspaceNavigation`、`getWork` 三个查询。发送、创建、设置、团队控制、运行时事件和取消接口已删除。
- `HistoricalBotReader` 校验用户、Bot、团队和会话身份，读取时关闭消息补录。导航使用 `snapshot({repair:false})`，重复查询不会重建空 Bot 工作空间。
- 历史消息、工具记录、协作来源、回复用量、报告图片、文件和 HTML 导出保留。历史事项显示原有执行用量。
- 通知打开历史消息时解析原会话与原请求；分页结果、取消和迟到导航均有范围检查。
- Goal 的创建、标准更新、证据校验、分支关联和完成仍由 `ConversationGoalService` → `WorkService` 处理。保留底层身份、原始执行快照、仓库和投影。

## 已删除

独立 Bot 创建与管理、前台编排、协作派发、后台执行适配器、自动唤醒、团队创建与重规划、旧头像管理和素材构建、前端 Bot 草稿与选择缓存、旧渠道绑定保存接口、旧 Bot 提醒投递器，以及只供旧 Bot 工具注册使用的 Google Workspace 适配层。

普通任务执行、子代理、Goal、邮箱/日历服务、自动化和历史数据继续保留。`DurableBotService` / `DurableBotRuntime` 是普通任务也使用的当前 Pi 执行后端；其名字中的 Bot 不表示独立 Bot 产品模式。

未删除现有数据库、历史消息或成果文件。历史记录所需的表、DTO 和来源身份继续保留；移除的管理能力不会通过兼容接口恢复。

## 验证入口

`pnpm -s test:retired-bot-contract` 运行真实 SQLite 的历史读取与 Goal 变更，检查接口、前端状态和团队写入口的退役边界。

历史导航、分页、报告图片、HTML 导出、通知定位、记忆正确性、完整持久向量规模和普通任务/子代理的测试继续保留。混合测试中的旧 Bot 用例已删除或改走当前任务接口。已失效的专用测试、脚本命令和门禁分类一并移除，失败基线没有扩大。

开发桌面检查统一使用 `desktop-dev-harness.cjs`，通过 `pnpm dev` 启动隔离配置与 Electron profile。设置与菜单用例无需模型服务；上下文实测使用普通任务入口与公开模型目录，不读取真实个人凭据。没有桌面、可用模型或必要平台条件时仍须失败。

`test:bot-workspace-navigation-ui` 是 DOM 行为检查；它不证明桌面布局。`test:all` 仍只代表无头门禁，完整 GUI、联网和发行包验收另计。

其他 `docs/bot-*.md` 中的独立 Bot 操作流程保留为历史设计资料，已经失效的测试命令不再作为当前验收入口。
