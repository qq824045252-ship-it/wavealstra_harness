## 3. 最终架构（V3.5 §101 落地）

```
Artifact Domain          = Artifact 是什么（SQLite artifacts 表 = 唯一持久真相）
  ArtifactStorage        = managed-content 物理落盘/orphan GC
  ArtifactRepository     = metadata 持久化（commit point）
  ArtifactRegistry       = runtime cache（可从 Repository 全量重建）
  ArtifactService        = 唯一业务 façade（五步注册事务/refresh/hydrate）
ArtifactSourceResolver   = Runtime 的 Domain 唯一入口（filePathOf/contentOf/rootOf）
WebArtifactRuntime       = Artifact 怎么成为 Web 资源（安全 contract 单点）
ArtifactProtocol         = 浏览器如何请求（mybuddy-artifact:// 协议层）
NativeSurfaceCoordinator = WCV 何时显示/在哪（唯一显示决策层）
ArtifactPreviewHost      = 哑 host（create/load/bounds/navigation）
CdpElementInspector      = CDP 细节（attach/Overlay inspect/resolve）
DesignModeController     = Design Mode 状态机
SelectionStore           = Selection 唯一真相源（active/stale/empty）
PromptContextService     = 采集（只信任 ACTIVE）
PromptContextSanitizer   = §82 UNTRUSTED 清洗
PromptContextFormatter   = → Agent message（UNTRUSTED 声明包裹）
```
