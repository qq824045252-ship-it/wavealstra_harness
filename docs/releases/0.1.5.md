# MyBuddy 0.1.5

- Bot 替代原设计模式，执行、工具调度、取消和恢复由 Pi Durable 原生语义管理，不再套用 MyBuddy 情景黑白名单、审批等待、执行门禁或产物显示过滤。
- Bot 通过 Tag 切换原生模式和 Code Mode；沿用模型、认证、项目、工作目录、记忆和预设配置。日常办公与代码开发保留现有执行路径。
- 界面从 Durable 持久状态恢复完整会话，包括进行中的输出、工具调用和排队输入。记忆提取与用量统计避免重连后重复计入。
- 更新 Bot 默认提示词，迁移旧工厂设计提示词，保留自定义提示词。补回首字前的等待反馈、消息进入动画和可恢复的完成耗时。
- 删除通用设计 Tag，将“网页原型”改名为 Penpot 并移至日常办公，保留其能力与配置。旧设计任务进入可恢复的回收站。

实现边界与验证入口见 [Bot / Pi Durable](../bot-durable.md)。
