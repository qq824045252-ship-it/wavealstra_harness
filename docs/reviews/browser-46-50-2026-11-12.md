## 执行与读取契约

`find`、`inspect`、`wait_for` 支持 selector、role、name 或 text。动作只使用当前页面已经观察的实际节点。节点替换、语义变化、多个可见匹配、禁用、只读和遮挡会使操作停止。焦点或无关文字变化不会单独撤销稳定节点。

输入通过固定 WebContents 的 Electron 检查会话发送可信事件。页面布局和节点检查仍复用 `UiAutomationService`。鼠标或键盘派发后等待目标收到事件，填写还比较实际控件内容。`confirmed` 表示输入已被控件接受，业务完成仍须用具体的 `after` 条件或提交结果判断。测试核验了真实提交数据，包括 React 受控字段。

临时呈现窗口复用 BrowserHost 的现有机制，不选择其它任务标签，也不恢复最小化主窗口。输入时暂停检查 Overlay，完成后恢复原检查会话。实机探针证实，当前 Chromium 在 Overlay 代理开启时可能拦截输入，即便检查模式已设为 `none`；`Overlay.disable` 后相同点击到达页面。

读取默认保留交互观察，`mode: "text"` 不返回元素列表。正文与元素分别报告截断和总量。`nextCursor` 绑定页面文档、快照和偏移；导航或真实 DOM 版本改变后拒绝续读。内部引用属性维护不会使游标失效。全页版本对游标仍采用保守失效策略，节点动作采用局部重验。

每个文档保存一份最多 4M UTF-16 单元的原文快照。超出上限需缩小 selector。宿主最多保存 128 份观察，每份最多 512 个引用或别名。分页不会切开代理对。iframe 和 Shadow DOM 内容明确标为不覆盖；直接读取 iframe 元素返回 `UNSUPPORTED_SCOPE`。

`outcome.dispatch` 区分 `not_started` 和 `dispatched`，`effect` 区分 `none`、`unknown` 和 `confirmed`。输入派发后的超时不会被写成“没有执行”。只读失败没有伪造宿主未开始证明。后续观察失败保留在 `observation.status: "failed"`，不改写已经确认的动作结果。

真实模型命令使用隔离 HOME、数据库和 Chromium profile，不读取真实账号凭据。模型目录来自本机网关。输出上限取目录配置，不硬编码 4096。

```powershell
pnpm -s test:browser-production-live -- --models opendesign/deepseek-v4.1-flash-eco --reasoning max
pnpm -s test:browser-production-live -- --variant candidate --models codex/gpt-6.1-sol --reasoning low --cases 'short,long,table,async,form,popup,partial,non-browser,bot-work'
node scripts/browser-benchmark-report.mjs <本轮输出目录>
```

默认 A/B 按同一模型、同一道题交错执行，下一轮交换 A/B 顺序。`--repeats` 指定重复数，`--baseline` 接受完整 SHA。切换六个基线文件：浏览器执行、UI 执行、工具注册、Durable 工具桥接、BrowserHost、PageInspectionService；保存原文供核对。其它当前源码（包括恢复策略和原有 dirty work）保持一致。因此这是浏览器路径的受控对照，不是整个仓库两个提交的对照。源码清单、预先存在的 dirty paths 和实际 bundle 哈希写入 `manifest.json`。

`wallMs` 从 AgentService 受理前计到持久化结果读回，包含宿主执行与模型等待，未测完整 UI 输入到渲染。进程启动至退出另记为 `processWallMs`。模型请求、browser 工具调用、renderer JS、Electron 输入和 CDP 命令分别记录；阶段可能重叠，不相加冒充整体时间。

`prompt_tokens` 包含提供方报告的缓存读取。缓存率的分母为所有有完整 usage 的请求输入总量。缓存读为零和有缓存读的请求分开保留；新建本机 profile 不证明提供方缓存冷启动。缓存写入量和费用没有证据时为 `null`，不把目录中的零费率当成免费。摘要同时保留三位小数 M 与原始整数。

无效重读指标只统计没有输入或导航介入、范围与偏移相同、返回正文和目标完全重复的读取。这是保守下界，不把所有重复 read 或装饰变化自动判作无效。
