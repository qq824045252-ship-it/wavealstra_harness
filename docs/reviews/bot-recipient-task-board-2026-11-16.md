# 受托方任务看板

基线：main 7f0936b0。本实现从原需求与验证说明重新实现，没有使用不可访问的 caed81f。

- 只在宿主绑定正式 Work 后，才按接收 Bot 与协作 ID 合并。同名任务不串卡；打招呼、问答与未建 Work 的协作保持消息样式。
- 接单显示公开委托和补充要求；执行显示受托方回复及阶段成果；交付保留报告和文件操作；反馈保留委托方反馈和单独标注的记录摘要。内部协作提示不进入接单正文。
- 只按持久消息、协作回合或唯一 Work 关联归组。不覆盖用户输入、多任务共用回复或委托方的卡片。回传状态与 Work 是否成功分别显示。
- 轮转刷新最多 100 条，晚到的旧页不能回退已知状态；补页与 Work 绑定不改变卡片身份。手选阶段不因更新而跳，输入框、草稿和导航原地保留。
- 不修改调度、数据库、授权或安装包。

定向验证：类型检查；受托投影 24 项；受托卡片 DOM 12 项；实际工作台 React 渲染 13 项（原委托方 12 项、受托方 1 项）；收件刷新/分页、委托任务投影及续写回放。Vivion Electron 使用隔离用户资料和模拟宿主，验证 390px 窄屏、回件更新、加载旧页、键盘打开协作记录及返回焦点。没有运行真实模型或改动用户实际会话。

命令：`pnpm -s test:bot-received-tasks`、`pnpm -s test:bot-received-task-card-ui`、
`pnpm -s test:bot-task-reply-ui`。定位受托 Electron 场景时用
`BOT_COLLABORATION_RECIPIENT_ONLY=1` 运行 `pnpm -s test:bot-collaboration-ui`。
