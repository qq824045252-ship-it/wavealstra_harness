# Bot 即时查询备用恢复（2026-11-11）

## 确定缺陷

已配置 fallback 顺序时，首选供应商缺少可用配置/凭据/模型，`runMeasuredSearch` 实际没有发请求，却生成普通 error。上层仅按 transient/quota/network 决定继续，因而在 unknown 处退出。备用供应商从未调用。

行为复现：两条查询，配置 codex → tavily，codex 在隔离夹具不可用，Tavily 可用。修前请求数 **0（预期 2）**；修后两条查询分别由备用返回来源。

## 修改

- 为本地未发起请求保留结构化 `skippedReason`（unavailable / request-limit），不解析供应商返回文本推断是否执行。
- fallback 仅对 unavailable 继续既有配置列表；原本的来源、错误与部分覆盖报告全部保留。
- 无请求不消耗请求次数，后续查询预留次数不变。
- 显式指定供应商不改道；实际 401 不被当作本地未配置；503 继续原有降级行为。
- 不新增审批、收件箱、后台 Work 或无限重试；不改生产模型/搜索配置。
