# 搜索来源保真与数值定义（2026-11-11）

## 原因与修复

Exa 每条来源的 snippet 原来固定为空。API highlights/text、answer citations text、MCP text/content 均丢失；模型看到的主要是汇总 answer，而 report 将该整体截断至1600字，后续来源只有 URL。另 MCP 只取第一段 text block。

修复保留每个 URL 自己的摘录（highlights → text → content，最多3000字符）。没有摘录保持空，不把总摘要复制给其他来源。多个文本块都保留，多个完整 JSON 块合成结果数组而非拼出无效 JSON。原有 report 的来源预览上限不增加。

Bot 与工具结果补充轻量通用要求：数值/单位/日期/适用对象/定义与同一来源对应；摘录不足则只读最相关原页或说明未确认。没有新审批、没有强制每问多跑模型、没有以具体科学知识硬编码判分。

## 验证

- 复现前：MCP来源应有 `Sidereal rotation period: 24.6229 hours.`，实际是空字符串。
- 修后25项搜索专项通过，覆盖API highlights/citations、MCP文本/JSON/多文本块/多JSON块、长总摘要截断后每个来源仍保真、缺证据不编造。
- typecheck通过，scripts 0错误。
- 非故障聚合413通过，0失败；沿用前轮20项故障恢复暂缓清单，不改变正式门禁或基线。

## 六类真实模型与人工原文核对

真实模型 `opendesign/deepseek-v4.1-flash-eco`，临时HOME+真实Electron renderer+公网Exa。六类：天文、食品安全、消费权利、编程API、HTTP标准、计量单位。每轮独立工具证据，不借历史结果。

独立通过HTTP读取并保存NASA Mars Fact Sheet、FDA Safe Food Handling、欧盟Your Europe、Node.js官方API、RFC9110、NIST SI Units–Length原文及SHA256。对照结果：
- 火星：24.6229小时恒星自转周期，24.6597小时太阳日，已区分；未再混称。
- FDA：冰箱≤40°F、冰柜≤0°F；2小时，高于90°F时1小时。
- 欧盟：商品交付日与服务合同订立日不同。原文服务精确表述为“14 days after the day the contract was agreed”；答复中文简写不应当作逐字法律引用。
- Node：无encoding为Buffer，utf8为字符串。
- RFC：120是秒，非毫秒；还可HTTP-date。
- NIST：299792458 m/s是固定精确值。

**不宣称严格一手原文链路6/6通过。** 数值/单位核心核对通过，但模型内fetch_content因隔离HOME没有现有代理识别资料，被fake-IP地址防护拒绝。天文/HTTP回复采用了转载/二手来源并明说未核验原页，故一手来源对应仍有缺口。食品等也明确仅据摘要。真实端到端时间15.5–31.9秒，包含失败原页读取，不宣称快返性能改善。

尝试复用已有web-watch验收的代理必要字段复制机制时，工具拒绝读取用户Clash配置，未执行。没有关闭SSRF、绕过拒绝或修改系统代理。原页工具完整验收需取得具体配置使用授权后另跑。

权威独立原文证据与六个模型回答见同名JSON。原始验收产物在out/diagnostics/bot-search-grounding/live/。不修改生产实例，不打包，不做崩溃注入。

## 首轮细查补充（不能漏报）

火星首轮虽然区分两个小时数，但额外添加的 `24小时39分35.244秒` 与所引用 `24.6597小时` 不相等（按该小时数换算应是 `24小时39分34.92秒`）。这是无依据的额外精细换算，本轮不能判整条答案完全正确。已追加通用要求：非必要不自行添加精细换算/衍生数字，必要换算标约数且精度不高于来源；已完整重跑六类，不用天文数字硬编码规则，也不增加审核模型。

日期字段边界：这次保留来源正文中的日期语义，但没有新增 `publishedDate → publishedAt` 元数据映射或日期展示，不宣称该遗留能力已完成。

## 最终六类复验

最终模型回复的六类核心数值、单位与定义均已人工对照独立下载的权威原文。火星不再把秒数称为24.6597小时的换算，而是单独归属NASA GISS的原文；又独立下载GISS页面，确认其确实写着“24 hours 39 minutes 35.244 seconds”。两个来源的不同精度保留而不做等式。食品未擅自加摄氏温度转换。

最终耗时13.97–56.90秒；HTTP案例尝试多个原页仍失败，不能称快返改善。模型内原页工具验收仍不完整，外部独立原文核对不冒充模型工具读页成功。既有代理配置读取未获批准，未执行。最终报告JSON保留首轮与复验答案，便于对照。

最终类型检查与25项搜索专项通过；最终Exa解析改动后413项非故障聚合通过，之后仅补提示词精度句及两个夹具边界并重跑类型/专项与六类真实模型。未修改产品日期字段展示。
