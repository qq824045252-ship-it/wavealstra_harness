# 日常待办与承诺：按期限和待回复状态查询

## 实际缺口与范围

基于 `ca1a5dd` 的真实 SQLite 复现：75条日常事项中，10条较早创建的紧急承诺在默认最新20项里全部不可见；原模型工具不接受期限窗口或期限排序，不能直接在全库存里回答“今天到期哪些”“哪些过期了”“哪些等我回复”。这不是调度器漏发修复，而是现有事项查询缺少日常跟进筛选能力。

复用原 `work_query_status`、Work记录和权限，不创建新的待办库、收件箱、审批或后台任务。

- `deadlineFrom`（含）/`deadlineBefore`（不含）按承诺期限筛选；空期限不匹配，不混淆下一次检查时间。
- `needsUserInput` 按当前开放且待用户输入的阻碍筛选；已解决与纯系统故障分开。
- `deadline_asc` 期限优先，空期限置后；相同期限按创建时间和ID稳定排序。默认创建时间顺序不变。
- 在SQLite先筛选、计数，再有界分页；游标绑定用户/Bot/团队及所有筛选与排序，续页参数保留时间窗口。
- 不改变控制权限、调度、期限跟进或业务执行；不因为查询而启动任务。

- `test:bot-work-foreground-contract`、`test:bot-work-team-access` 通过。
- `test:bot-conversation-ui` 通过；`test:architecture` 278通过/0失败；类型检查通过。
- 独立静态复核未发现生产逻辑或权限问题；复核指出的NULL游标分支、双重时间并列及最终答复多报代号的验收缺口均补入测试。
- 本轮未跑全量回归，未构建发行包、未更新生产实例、未进行实机崩溃故障注入。主仓库原有未跟踪的崩溃脚本未触碰。

## 真实模型验证设计与边界

入口：`BOT_FRONTDOOR_MODEL=opendesign/deepseek-v4.1-flash-eco BOT_WORK_DEV_HEADLESS=1 pnpm -s test:bot-frontdoor:live --commitment-query`。

在隔离HOME中明确建立165条暂停事项夹具，由实际前台模型通过实际Electron renderer调用真实查询服务。覆盖六类业务与查询意图：

1. 发布承诺逾期清点：只返回仍未结束的两项，排除已关闭、外用户和较新的未来项。
2. 上海今日库存承诺：按Asia/Shanghai当地零点到次日零点，仅命中今日项。
3. 纽约配置审计：2027-03-14夏令时开始日按23小时本地日期窗口，仅命中当日项。
4. 合同待用户输入：仅列仍需采购数量的事项，区别已解决等待与外部服务维护。
5. 日志排障优先级：期限最早的三项优先，而非最新创建项或空期限项。
6. 运单跨页盘点：每页10项，完整读出23项，核对最终代号无遗漏、无新增。

这是自然语言**查询**验收，不冒充自然语言创建、真实工作内容执行或物理桌面键鼠验收。所有业务夹具为测试生成；没有读取生产资料或执行这些事项。

首轮六类产品流程实际走完；模型一次抄错游标被拒绝后重新查询并完成23项。验收脚本错误地对失败回执读取total而退出，已改成分别核对成功页与错误回执。后续调试发现模型可以先宽范围查询再缩小主题，也可以完整读取一个日期窗口后按业务类别回答；旧脚本把这类正确路径误算成额外结果。修正为按题目业务类别核对真实来源ID，广义查询必须取完分页，再独立核对最终代号集合与总数。错误回执和完整查询证据都保留，每组执行六类后再统一判定，不放宽产品筛选契约。

证据保留在独立副本的 `out/diagnostics/bot-commitment-query/live/`；不提交完整测试对话和供应商请求记录。

## 最终保留证据

最终一组六类真实模型请求均执行到终态，来源ID、日期窗口、排序和23项跨页回传正确；其中五类自动判定通过。合同答复用“纯外部故障，不涉及需要你提供信息”明确排除非待输入事项，旧的措辞断言未覆盖该表达，使原 live 命令退出1；这个失败报告原样保留，**不称该命令全绿**。

修复仅在验收器中：排除代号必须来自真实工具回执中 `needsUserInput=false` 的记录，并在答复中明确否定；虚构代号仍拒绝。对同一组已保留的六份真实答复做离线重验全部通过，并用错误总数、虚构运单、把非待输入合同当成待输入、虚构合同四个负样本证实不会误报成功。另从该隔离数据库回查仍为165条夹具、执行绑定为0。此离线重验没有重新调用模型，也不冒充新一轮在线测试。修正后的完整 live 命令未另行重跑，避免与后续响应性验收争用资源。

对应证据是原 `report.json`、完整六类 `progress.json`、`answer-recheck.json`。功能与断言边界已人工核对；真实前台模型的自然语言表达仍可能变化，不把正则断言当成全面语义证明。
