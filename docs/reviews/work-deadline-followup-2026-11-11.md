# 承诺期限跟进：公平扫描与暂停恢复

## 修复范围

- 原扫描固定读取最早64条到期事项，再在循环中跳过已处理实例。历史记录达到64条后，后续期限永远无法进入扫描。
- 暂停期间到期被记成 `followed-up`，但没有实际事件；恢复后也被当成已跟进，永久漏掉原委托期限。
- 现在先按当前 revision/期限筛选未处理实例再限制批次；已暂停记录保留事实，恢复后只补一次独立只读跟进。成功入队后清除旧暂停提示，不改变原周期、不重新执行业务写入、不新增审批。
- 已派发的期限、改期/移除/关闭后的旧期限不会再派发。

## 行为验证

真实 SQLite 服务测试覆盖130条到期按有界批次全部跟进、重复扫描零重复、70条暂停期限不挤占后续active事项、暂停时不执行、恢复只补一次、再次暂停恢复不重复、改期不提前触发旧期限、移除期限不恢复旧事件。

类型检查通过；调度、前台创建、前台监督专项通过。非故障注入默认门禁413通过/0失败/0已知/0回归（2.4分钟）。正式聚合命令与失败基线未变，暂缓名单沿用提醒验收的20项故障/恢复用例。
