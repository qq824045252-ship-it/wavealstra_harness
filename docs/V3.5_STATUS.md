## 4. Known Limitations（冻结）

### DOCX
- 使用 docx-preview 渲染；支持常规正文/表格/图片/header/footer
- 分页主要依赖显式 page break / section（无自动高度分页）
- 不等价于 Microsoft Word 完整排版引擎
- 不支持编辑/writeback

### XLSX
- SheetJS parse + 自研渲染器；支持多 sheet / frozen panes / merged cells / styles
- 公式显示 cached value，**不执行公式重算**
- 不提供编辑

### PPTX
- 自研 OOXML renderer；支持基础文本/图片/表格/shape/fill/rotation/z-order/group
- 不支持 PowerPoint 完整动画系统
- 不保证复杂 SmartArt/master/theme 100% fidelity
- 不提供编辑

### PDF
- pdf.js（legacy build）viewer；支持连续滚动/text layer/search/zoom/跳转
- viewer only：不支持 annotation/edit/sign/reorder/writeback

### 通用
- Monaco 编辑态预览不写回（写回需 Domain 内容更新 IPC）
- Viewer 均为只读展示，无 writeback
