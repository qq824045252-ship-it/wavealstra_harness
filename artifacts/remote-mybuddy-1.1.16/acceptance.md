# Mybuddy 安卓 1.1.16 验收

已覆盖安装至 Honor AAK-AN00，版本号 1.1.16（18），保留原有 HTTPS 配对。

本版输入区保持 58px。模型与权限按钮仅显示图标，点击后查看与选择具体内容。模型列表来自电脑端真实目录，权限支持跟随电脑 / 当前任务、默认权限、只读模式、允许完全访问。

安卓端已删除扫码、相册二维码入口、扫描组件及样式和对应说明。连接页保留 USB 自动配对、局域网与 HTTPS 的完整链接粘贴 / 手动输入，以及已配对设备修改连接地址。

| 电脑端入口 / 配置 | 安卓端对应 |
| --- | --- |
| 设置 → 远程连接 → USB 数据线 → USB 配对 | USB 连接步骤及自动接收配对链接 |
| 访问范围 → 局域网；添加设备 | 查找电脑、粘贴或输入完整配对链接 |
| HTTPS 入口；添加设备 | HTTPS 远程连接及链接配对 |
| 监听端口 / 访问地址 | 修改连接地址 / 自定义端口 |
| 模型目录 / 默认模型 | 输入框模型图标 → 模型选项 |
| 默认权限 / 只读模式 / 允许完全访问 | 输入框盾牌图标 → 权限选项 |
| 项目 / 附件上传 | 附件菜单中的项目选择、拍照、图片、文件 |
| 历史任务 / 通知 | 菜单中的任务列表和通知 |

真机结果：两个按钮的可见文字均为空、各包含一个图标，宽度均为 36px；模型弹层含跟随选项及电脑端 6 个模型；4 个权限选项可用，切换只读后正确生效于界面，验收后恢复跟随。连接页三个标签均无二维码内容、无扫描组件。返回聊天后保留当前任务。

HTTPS 真机认证返回 200，同步 6 个模型、1 个项目；最终未配置 USB reverse。此前 1.1.14 使用 HTTPS 完成真实只读任务，电脑端回读 permission=readonly，回复 MYBUDDY_REMOTE_58_OK SUM=6；1.1.16 再次从 HTTPS 正常读取该历史结果。本版未重复提交验收消息。

本版通过 TypeScript、Vite、Android Gradle 构建，以及 37 项渲染回归、4 项连接 / 权限协议检查、6 项连接 UI 检查。本目录随 Git 提交保留安装包、结构化验收记录及测试截图；真机截图保留在本地。
