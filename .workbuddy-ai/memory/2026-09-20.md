## Markdown 渲染视觉审查（只读，未改代码）

产出 `docs/markdown-render-visual-review.md`。

### 架构事实（下次直接复用，别再重新探索）

- 双渲染器：`chat/ChatMarkdown.tsx`（markstream-react 0.0.55，流式）/ `common/Markdown.tsx`（react-markdown 10 + remark-gfm）。
- 主样式 `styles/markdown.css`（848 行）三套：`.md` / `.md-chat`（`em` 相对）/ `.md-doc`（`px` 绝对）—— **两套尺寸体系是所有不一致的根因**。
- 代码主题：13 套 `--code-theme-*` 在 `styles/systemTypography.css:245-370`，由 `appStore.ts` / `SettingsModal.tsx` 写 `document.documentElement.dataset.codeTheme` 驱动（默认 everforest）。**已验证链路是通的**，不是死代码。
- 聊天区表格不走 `markdown.css`：markstream 输出 `.table-node` / `.table-node-wrapper`，被 `markstream-react/index.css`（Tailwind，`--table-border` 默认 `#cbd5e1`、`my-8`=32px）接管。

### 主要问题（P0）

1. 代码块外壳脱节：`.md-pre` / `.md-code-header` 仍用 `--bg-code`（#f3f3f1 恒浅灰），而 `pre` 被 `html[data-code-theme]` 改写 → 标题条与代码面双色；dark-only 主题（dracula/nord/monokai）在浅色模式下是「浅灰条 + 近黑体」。
2. 标题层级坍塌：h4 15.6px≈正文 15px；`.md-doc h3` 15px=正文；**h5/h6 两个 variant 都无样式**，回落 UA 默认 12.45/10.05px，比正文还小（层级反转）。
3. 表格：`border-radius` + `overflow:hidden` 在 `border-collapse: collapse` 上不生效（圆角一直没生效）；无横向滚动容器；聊天区与文档区两套外观。

### P1

字体栈 `--font-mono` 无中文回退（行内代码中英混排基线错位）；`font-weight: 650` 在 PingFang/雅黑不存在（macOS→Semibold、Windows→Bold，跨端跳档）；全局 `word-break: break-word` 切断英文长词；链接无 hover/focus 且长 URL 溢出；缺失 kbd/mark/dl/figcaption/sup/sub + 聊天区任务列表 checkbox。

### 修复已落地（同日）

改动 4 个文件：`styles/global.css`（新增 `--md-*` 排版令牌 + `--font-mono` 补中文回退）、`styles/markdown.css`（标题令牌化 + h5/h6、`650→600`、表格 `separate`+滚动容器、断行收敛、链接 hover/focus、补齐缺失元素、`pre` tab-size/max-height）、`styles/systemTypography.css`（`.md-pre`/`.md-code-header` 跟随 `--code-theme-bg|fg`）、`components/common/Markdown.tsx`（新增 `Table` 组件注册到 components）。

**踩坑记录（重要，下次改这类样式直接复用）**：
- markstream 自带 Tailwind 工具类（`.markstream-react .my-8`、`.text-sm`）特异性 `(0,2,0)`，`.md-chat .table-node` 同为 `(0,2,0)` → 平手，胜负取决于 CSS 加载顺序。**必须用 `.md.md-chat table` 抬到 `(0,3,0)` 才能稳定压过。**
- markstream 渲染的表格**不保证有 `tbody`**，斑马纹选择器不能写 `tbody tr`。
- `html[data-code-theme] .md-chat pre { border-color }` 是无效规则（`pre` 已 `border: none`），代码块边框画在外层 `.md-pre` 上 —— 改代码主题配色要改 `.md-pre`。
- `border-radius` + `overflow:hidden` 在 `border-collapse: collapse` 的 `<table>` 上不生效，圆角必须靠外层容器裁剪。

验证：`tsc --noEmit -p tsconfig.web.json` 通过；`test:chat-markdown` 96/96；`test:wave5a` 73/73。`test:visual-polish-ux` 失败但**与本次改动无关**（断言查 `ExecutionTimeline.tsx` 的 `<span>Thinking</span>`，属改动前既有失败）。
