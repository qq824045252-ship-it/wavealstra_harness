# Selected architecture

Native Electron is the selected base. Keep BrowserHost as the tab and presentation owner, PageInspectionSession as the only debugger owner, and BrowserAutomationService as the task-authorized tool boundary. BrowserDocumentContext owns exact frame/document binding and coordinate conversion. Shared document helpers handle open Shadow DOM without patching page prototypes. Dedicated bounded algorithms handle events, transfers, gestures, assertions and collections under the same deadline.

The framework candidate contributed the narrow driver boundary, explicit business evidence and compatibility veto. No maintained framework has demonstrated supported injection into this exact debugger transport, so no new browser process, debug socket or private framework transport is introduced.

The independent cross-judge preferred native on ownership, explicit outcomes and feasibility. Its iframe-removal scope flags were superseded when the user cancelled deletion and restored iframe support. The authoritative current scope is requirements.json: retain existing app previews and implement all original P0/P1 capabilities.

Only verified requirements may be marked complete. Module probes do not prove tool-bridge acceptance. Existing input-level effect confirmation remains distinct from business assertions. Failed assertions and navigation re-observation never replay mutations. Collections need positive terminal/count evidence. Visual input requires fresh screenshot provenance. User handoff must use the actual task waiting/continue lifecycle.
