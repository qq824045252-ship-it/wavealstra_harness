# UI gesture integration

`UiAutomationService` retains existing observed-node and actionability checks. Click accepts `button` (`left` or `right`), `clickCount` (1 or 2; right only supports 1), and `modifiers` (`control`, `alt`, `shift`, `meta`). A left single click requires a trusted `click` receipt; left double click requires `dblclick`; right click requires `contextmenu`. `onActionAccepted` still marks actual receipt, not a business assertion. A link navigation or cancellation after dispatch remains an unknown-effect case rather than a reason to replay.

`action: 'drag'` takes the observed source locator and `dragTo`, an observed selector for the same document; pass both refs in `observedSelectors` and the original target semantics in `dragToExpected`. It resolves and validates both, checks their hit targets after the initial pointer move, sends bounded trusted pointer waypoints, and requires a trusted `mouseup` at the destination. The input surface must remain leased until the function and its release cleanup settle. The native pointer route can drive pointer-based widgets; a DOM `mouseup` receipt does not prove an application-specific drop or business effect. HTML drag data is a separate helper and is not exposed by this action.

`action: 'fill'` accepts `inputMode:'sequential'` and optional `delayMs` for per-code-point trusted insertion after existing focus/select-all behavior; ordinary fill and contenteditable remain supported. Native date, time, datetime-local, month and week inputs automatically use the bounded synthetic setter and synthetic input/change events with exact readback; optional `dateType` demands the matching native input type. The detail reports `synthetic-setter`, and no trusted input receipt is claimed. Frame selection, task/tab identity, observed-ref ownership, public validation and business assertions remain the browser service's responsibility.

Validation used an isolated Electron profile and real `UiAutomationService`, `PageInspectionSession` and `browserNativeInput`: `pnpm exec electron scripts/ui-gestures-integration-electron-test.ts` passed double/right/control-click, pointer drag, stale destination rejection, cancellation with own button release, sequential Unicode input, contenteditable fill and native date setter with synthetic event evidence. The focused existing `pnpm -s test:ui-automation-cancellation` and `pnpm -s test:browser-task-execution-electron` also passed. The test bundles sources in memory; the existing pnpm tests compile only their own test fixtures. The new public browser tool contract and full repository gate were not exercised by this test.
