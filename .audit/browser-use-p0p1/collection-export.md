# Collection export integration

`exportBrowserCollection({ taskRoot, collection, scope })` writes the complete `CollectionResult` as UTF-8 JSON and returns `{ path, rootDir, bytes, sha256 }`. The caller supplies the trusted host-owned task root, not a tool-selected destination. The root is canonicalized; each export creates a fresh randomly named child directory and a `wx` file, then reads and hashes the actual file, checks byte count and hash against the serialized content, and reports the canonical task root for artifact registration. Register the returned `path` as a task-scoped artifact and preserve the original collection status and evidence; exporting a partial collection does not make it complete.

The shared scope is checked around filesystem operations and marked dispatched immediately before the first filesystem mutation. Filesystem calls cannot be cancelled atomically; the helper waits for each operation to settle before proceeding or reporting deadline/cancellation. A `BrowserCollectionExportError` carries `details.stage`, and when known `details.path` and `details.directory`; already-created output is retained for inspection. The integration must propagate those details and the existing action outcome, rather than treating an export or artifact-registration failure as evidence that prior collection advances did not happen. Cancellation during a filesystem await may thus return after that call settles, with the retained path if one was created.

Validation: `node scripts/browser-collection-export-test.ts` passed for a 480-row Unicode result with long cells, deep equality of the parsed artifact against all literal source rows, canonical root, distinct unique destinations, actual file length and SHA-256, pre-dispatch cancellation without creation, and injected post-write interruption with the retained exact file path and content. This is a standalone filesystem test; browser tool bridge and artifact registration are not exercised. Node module typecheck filtered to this module had no diagnostics, and `node scripts/typecheck-scripts.mjs` passed with no added errors.
