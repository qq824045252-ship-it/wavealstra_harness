# MyBuddy 导航

先用一句话给出最短点击路径，再说明到达后选什么。只回答用户关心的入口。问“在哪里”时直接指路。问“我现在用的是哪个模型”“这次调用了什么”时，以当前对话信息或执行诊断里的记录为准。界面与这里的名称对不上时，可用当前会话提供的界面观察能力核对，或请用户说出看到的栏目。

## 从侧栏找功能

桌面最左边是一列图标，悬停可看名称。点图标后，旁边一列会显示该模块的内容。如果只看到图标，可以点左上「展开模块列表」。齿轮「设置」、铃铛「通知中心」和「用量统计」都在左下角。

| 用户想做什么 | 从哪里进去 |
| --- | --- |
| 发起对话、找之前聊过的任务 | MyBuddy → 新建任务，或点「筛选」按标题、状态和时间找任务。置顶、独立任务和工作空间都在这里。 |
| 给任务置顶、归档或改名 | MyBuddy → 找到任务，移到任务行上点「置顶」或「归档」。改名在该行「更多 → 重命名」。 |
| 找一个工作空间的文件、资料、记忆或终端 | MyBuddy → 工作空间 → 点空间名称 → 文件 / 资料 / 记忆 / 终端。点名称旁的箭头可以展开任务树。空间自己的简短笔记在「便签」，共享说明在「上下文」。 |
| 写笔记，找收藏或旧笔记 | 笔记 → 笔记范围 → 我的笔记或具体项目、工作空间，再选「全部笔记」「收藏」或「回收站」。 |
| 看项目进展、计划或资料 | 项目 → 进行中或已归档 → 选项目 → 健康 / 计划 / 任务 / 资料。这个项目自己的配置在项目内的「设置」。 |
| 定时提醒、周期执行、查自动化为什么没跑 | 自动化 → 添加自动化（加号）或从模板添加。已有计划在「定时任务」，每次执行的结果在「运行记录」。 |
| 找专家、安装技能、接 MCP 或连接器 | 扩展 → 专家插件 / 技能 / MCP / 连接器。技能页有「已安装」和「市场」。某个模式看不到已安装技能时，查「设置 → 模式与提示词」中该模式及 Tag 的技能策略。 |
| 找自己做的小工具、建一个 Gadget | 工作台 → 我的工具，或点「新建工具」。空间专用工具在 MyBuddy → 工作空间 → 点空间名称 → Gadgets。 |
| 找助手生成的文件 | 任务成果 → 全部成果，可搜索文件、任务或工作空间。 |
| 查通知或 Token 消耗 | 左下铃铛「通知中心」看发生了什么。左下「用量统计」选时间范围，看 Token、缓存命中率或导出 CSV。 |
| 看这次对话实际用了哪些模型和工具 | MyBuddy → 打开任务 → 聊天顶部「执行诊断」→ 展开对应轮次。要回到自己问过的那句话，点同一处的「历史提问」。 |
| 看助手现在在做什么、找这次任务的文件 | 打开任务 → 聊天右上「打开概览」。在右侧栏顶部选「概览与运行态」看主代理和子代理，选「任务产物」看本任务的输出，选「代码变更」看改动。 |
| 在对话旁打开网页、终端或文件夹 | 打开任务 → 聊天右上「打开概览」→ 在右侧栏顶部点「内置浏览器」「终端」或「工作空间文件」。同一排的「工作台」是当前任务的小工具。 |

## 从设置找选项

下表均从左下角齿轮「设置」开始。按用户想改变的对象选入口。

| 用户的说法 | 设置里的路径 |
| --- | --- |
| 换深色、改字体、关窗口后继续运行 | 系统设置 → 常规 → 外观 / 关闭时最小化到托盘 / 退出界面后保持助理在线。字号在「系统设置 → 字体」。 |
| 长对话何时压缩、网络代理、数据目录 | 系统设置 → 自动上下文管理 / 网络 / 存储。 |
| 登录模型服务商、填模型 API Key、换新对话的默认模型 | 模型 → 选模型提供商。新任务的默认值在该页「主对话默认」。 |
| 子代理用哪个模型、思考多深、能并行几个 | 子代理设置 → 子代理默认模型 / 子代理思考偏好 / 执行限制。要启用这项能力，去「工具能力 → 本机工具 → 子代理」。 |
| 换朗读声音或语速、转写音频、识图中文字、生图或视频 | 工具能力 → 语音与图像 → 文字转语音 / 语音转文字 / 图片文字识别 / 图片生成 / 视频生成。给工具配置服务商凭据，在「工具能力 → API 服务」。 |
| 选联网搜索供应商、视觉模型、多模型会诊 | 工具能力 → 搜索与图像理解 → 联网搜索 / 图像理解。会诊有单独的「工具能力 → 多模型会诊」。 |
| 启用浏览器或桌面操作、Office、CAD、流程图、命令、代码执行 | 工具能力 → 本机工具 → 界面与桌面操作 / Office Use / CAD Use / Draw.io Use / 命令执行 / 代码执行。 |
| 修改某个模式的提示词、Tag、技能白名单或 MCP 限制 | 模式与提示词 → 选模式 → 找相应策略或预设。「预览装配」可看已保存配置的效果。 |
| 给助手改名字、人设、对我的称呼 | 个性化 → 本地个性化资料 → 选对应项并点「编辑」。 |
| 看它记住了什么、管理公共记忆、审核学到的技能 | 记忆 → 全部记忆 / 公共记忆 / 技能学习。外部 Agent 的记忆授权在「记忆 → 外部访问」。 |
| 找资料时用关键词还是语义搜索 | 资料检索 → 默认检索方式。语义索引状态在同页「BGE-M3 语义索引」。 |
| 教它下次遇到某类问题怎么答 | 回答调度 → 回答规则。已有规则可以用「测试匹配」试一句话。 |
| 恢复归档的任务或空间，找刚删的任务 | 归档管理 → 任务 / 空间 → 恢复。已删除的任务去「归档管理 → 回收站」，随空间一起归档的任务先恢复所属空间。 |
| 让微信、QQ、飞书等渠道收到助理回复 | 助理设置 → 选具体渠道，例如「微信」「QQ」「飞书」。 |
| 用手机远程访问电脑上的 MyBuddy | 远程连接 → 连接地址，再到同页「配对新设备」。查看和撤销旧手机在「已配对设备」。 |
| 查看内置执行器，接外部 Agent | ACP 管理 → 内置执行器 · Pi Durable / 外部 Agent · ACP。 |
| 找分享记录或已归档任务 | 数据管理列出分享和发布条目。「已归档任务 → 管理」通向归档管理；分享和发布条目当前仅展示。 |
| 准备 Python、换项目解释器 | Python 运行时。项目解释器在「当前项目 Python」，环境排障在「运行时维护」。 |
| 查按键、关完成提醒、只保留错误提醒 | 键位查「快捷键」。提醒开关在「通知 → 通知方式」和「通知 → 任务」，可以分别设置「任务完成」「任务失败」「需要我处理」。 |
| 调整本机代码执行环境、恢复历史文件副本 | 安全中心 → 安全设置 / 历史备份。 |
| 看 MyBuddy 的版本 | 帮助与反馈。 |
